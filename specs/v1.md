# HyprMCP v1.0 Technical Specifications

## Overview

HyprMCP represents a sophisticated bridge between the emerging world of AI-powered desktop automation and the modern Wayland compositor ecosystem. As the Model Context Protocol (MCP) gains traction as the standard for AI-system integration, HyprMCP positions itself as the definitive solution for enabling AI assistants to interact intelligently with Hyprland-based desktop environments.

The fundamental challenge that HyprMCP addresses is the growing need for AI systems to move beyond text-only interactions and engage with the graphical desktop environment where users spend most of their productive time. Traditional automation tools require complex scripting and brittle window selectors, while modern AI assistants lack the contextual awareness needed to understand and manipulate the desktop environment effectively. HyprMCP bridges this gap by providing a standardized, secure, and semantically rich interface that allows AI systems to understand, query, and control desktop state with the same level of sophistication they bring to text processing.

The implementation leverages Zig's exceptional performance characteristics and C interoperability, ensuring compatibility with existing C-based desktop infrastructure while providing the memory safety and ease of development that modern system programming demands. This architectural decision positions HyprMCP to take advantage of Zig's growing ecosystem while maintaining direct integration with the Wayland protocol stack and Hyprland's IPC mechanisms.

## Architecture

The HyprMCP architecture follows established patterns from the Model Context Protocol specification while addressing the unique challenges of desktop environment integration. The design emphasizes the separation of concerns principle, with distinct layers handling protocol communication, desktop integration, and security enforcement. This modular approach not only enhances maintainability but also enables independent evolution of each component as the underlying technologies advance.

The architecture draws inspiration from successful MCP implementations across various domains, adapting proven patterns for the specific requirements of window management and desktop automation. The Protocol Layer implements the standard MCP request/response patterns with proper error handling and capability negotiation, while the Integration Layer provides domain-specific functionality through well-defined interfaces. The Transport Layer supports multiple communication mechanisms, ensuring flexibility for different deployment scenarios from local CLI tools to distributed AI systems.

### Core Components

#### 1. MCP Server (`src/server.zig`)

The MCP Server component represents the heart of the HyprMCP system, implementing the official Model Context Protocol specification with full support for the latest protocol features. This component is built using Zig's powerful async framework and the C++ MCP SDK through C bindings, which provides type-safe implementations of JSON-RPC message handling, automatic capability negotiation, and comprehensive error management.

The server architecture follows async programming paradigms, utilizing Zig's async/await ecosystem to handle concurrent requests efficiently. This design choice is particularly important for desktop automation scenarios where multiple AI agents might need to coordinate window management tasks simultaneously. The server maintains stateful connections while ensuring thread safety through Zig's compile-time memory safety guarantees and explicit memory management.

**Key Features**:
- **Protocol**: Model Context Protocol v2025-06-18 with full specification compliance
- **Transport**: JSON-RPC 2.0 over multiple transport mechanisms (stdio, HTTP, SSE)
- **Language**: Zig with async runtime for high-performance concurrent operations
- **Framework**: C++ MCP SDK integration via C bindings with automatic tool discovery and JSON schema generation

#### 2. Hyprland Integration (`src/hyprland/`)

The Hyprland Integration layer provides a robust interface to the Hyprland compositor through its sophisticated IPC protocol. This component abstracts the complexities of Hyprland's socket-based communication while providing a type-safe, async-first API that integrates seamlessly with the MCP protocol layer.

The integration leverages Hyprland's dual-socket architecture, using the command socket for state modifications and the event socket for real-time monitoring. This design enables both reactive responses to user-initiated changes and proactive automation based on desktop state transitions. The implementation includes comprehensive error handling for connection failures, protocol mismatches, and permission issues that commonly occur in multi-user or secure environments.

**Technical Specifications**:
- **IPC Protocol**: Hyprland Unix domain socket communication (`/tmp/hypr/$HYPRLAND_INSTANCE_SIGNATURE/.socket2.sock`)
- **Command Interface**: Direct dispatch to Hyprland compositor with response validation
- **Event Monitoring**: Real-time workspace and window state tracking with event filtering
- **State Management**: Cached state synchronization with conflict resolution

#### 3. Text Input System (`src/input/`)

The Text Input System represents a critical component that enables AI assistants to interact with applications through natural text input and keyboard automation. Built on the foundation of `wztype`, a modern Zig implementation of the wtype protocol, this system provides comprehensive support for complex input scenarios while maintaining security and reliability.

The system's architecture accounts for the intricacies of international text input, supporting full Unicode character sets, complex input method editors (IMEs), and platform-specific keyboard layouts. The implementation includes sophisticated timing controls and input validation to ensure reliable delivery of text while preventing common issues such as input race conditions and character corruption.

**Capabilities and Features**:
- **Backend**: `wztype` - A native Zig implementation of wtype optimized for Wayland environments
- **Unicode Support**: Full UTF-8 character set with proper handling of combining characters and emoji
- **Modifier Key Combinations**: Support for ctrl, alt, shift, and super key combinations with proper sequencing
- **Named Key Sequences**: Symbolic key names for function keys, navigation keys, and special characters
- **Timing Controls**: Configurable keystroke delays with adaptive timing based on target application characteristics
- **Protocol**: Wayland virtual keyboard protocol with XKB keymap integration

#### `hypr_focus_window`

**Purpose**: Focus specific window by address or criteria with intelligent fallback strategies and context preservation
**Parameters**:
- `address` (string, optional): Window address for precise targeting
- `class` (string, optional): Window class name for application-based focusing
- `title` (string, optional): Window title pattern with regex support

**Tool Annotations**:
- `destructiveHint`: false (non-destructive state change, preserves all window content)
- `idempotentHint`: true (focusing an already-focused window is safe and has no side effects)
- `openWorldHint`: false (affects only local desktop environment within security boundaries)

**Returns**: Success/failure status with previous focus state for restoration capabilities

**Advanced Implementation Features**:

```zig
const HyprFocusWindow = struct {
    const Self = @This();
    
    pub const annotations = mcp.ToolAnnotations{
        .title = "Focus Window",
        .read_only_hint = false,
        .destructive_hint = false,
        .idempotent_hint = true,
        .open_world_hint = false,
    };
    
    pub const description = "Focus window with intelligent fallback and context preservation";
    
    pub const Parameters = struct {
        address: ?[]const u8 = null,
        class: ?[]const u8 = null,
        title: ?[]const u8 = null,
    };
    
    pub fn execute(
        allocator: std.mem.Allocator,
        hypr_client: *hypr.Client,
        params: Parameters,
    ) !mcp.ToolResult {
        if (params.address == null and params.class == null and params.title == null) {
            return mcp.ToolResult.err("At least one parameter (address, class, or title) must be provided");
        }
        
        // Priority-based resolution: address > class > title
        const target_window = if (params.address) |addr| blk: {
            break :blk try hypr_client.getWindowByAddress(allocator, addr);
        } else if (params.class) |cls| blk: {
            const windows = try hypr_client.getWindows(allocator);
            defer allocator.free(windows);
            
            for (windows) |window| {
                if (std.mem.eql(u8, window.class, cls) and window.class.len > 0) {
                    break :blk window;
                }
            }
            return mcp.ToolResult.err("No window found with class: " ++ cls);
        } else if (params.title) |title_pattern| blk: {
            const windows = try hypr_client.getWindows(allocator);
            defer allocator.free(windows);
            
            // Simple pattern matching (could be enhanced with regex)
            for (windows) |window| {
                if (std.mem.indexOf(u8, window.title, title_pattern) != null) {
                    break :blk window;
                }
            }
            return mcp.ToolResult.err("No window found matching title pattern: " ++ title_pattern);
        } else unreachable;
        
        // Store previous focus state for restoration
        const previous_focus = try hypr_client.getActiveWindow(allocator);
        
        // Execute focus command with error handling
        const command = try std.fmt.allocPrint(allocator, "focuswindow address:{s}", .{target_window.address});
        defer allocator.free(command);
        
        try hypr_client.dispatchCommand(command);
        
        // Verify focus change with timeout protection
        const focus_verified = try verifyFocusChange(hypr_client, target_window.address, 500);
        
        const result = FocusResult{
            .success = focus_verified,
            .target_window = target_window.address,
            .previous_focus = if (previous_focus) |pf| pf.address else null,
            .workspace_changed = target_window.workspace != (if (previous_focus) |pf| pf.workspace else target_window.workspace),
        };
        
        const result_json = try json.stringify(allocator, result);
        return mcp.ToolResult.success(result_json);
    }
};

const FocusResult = struct {
    success: bool,
    target_window: []const u8,
    previous_focus: ?[]const u8,
    workspace_changed: bool,
};
```

**Advanced Implementation Architecture**:

```zig
const wztype = @import("wztype");
const std = @import("std");

const TypingResult = struct {
    success: bool,
    characters_typed: usize,
    total_duration_ms: u64,
    average_delay_ms: f64,
    application_context: ApplicationContext,
    errors: []TypingError,
};

const ApplicationContext = struct {
    focused_window: []const u8,
    application_class: []const u8,
    input_method_active: bool,
    estimated_processing_capability: InputProcessingLevel,
};

const HyprTypeText = struct {
    const Self = @This();
    
    pub const annotations = mcp.ToolAnnotations{
        .title = "Type Text",
        .read_only_hint = false,
        .destructive_hint = false,
        .idempotent_hint = false,
        .open_world_hint = false,
    };
    
    pub const description = "Type text with intelligent adaptation to application context and timing requirements";
    
    pub const Parameters = struct {
        text: []const u8,
        delay_ms: ?u32 = null,
        preserve_clipboard: ?bool = true,
        validate_focus: ?bool = true,
    };
    
    pub fn execute(
        allocator: std.mem.Allocator,
        wztype_client: *wztype.Client,
        hypr_client: *hypr.Client,
        params: Parameters,
    ) !mcp.ToolResult {
        const start_time = std.time.milliTimestamp();
        const preserve_clipboard = params.preserve_clipboard orelse true;
        const validate_focus = params.validate_focus orelse true;
        
        // Get application context for adaptive behavior
        const app_context = try getApplicationContext(allocator, hypr_client);
        
        // Validate focus if requested
        if (validate_focus) {
            try ensureValidFocusTarget(hypr_client, app_context.focused_window);
        }
        
        // Preserve clipboard if requested
        const original_clipboard = if (preserve_clipboard) 
            try getClipboardContent(allocator) 
        else 
            null;
        defer if (original_clipboard) |clip| allocator.free(clip);
        
        // Calculate adaptive timing based on application characteristics
        const adaptive_delay = params.delay_ms orelse calculateOptimalDelay(app_context);
        
        // Process text with Unicode normalization
        const normalized_text = try unicodeNormalize(allocator, params.text);
        defer allocator.free(normalized_text);
        
        const chunks = try chunkTextForProcessing(allocator, normalized_text, app_context);
        defer {
            for (chunks) |chunk| allocator.free(chunk);
            allocator.free(chunks);
        }
        
        var typing_errors = std.ArrayList(TypingError).init(allocator);
        defer typing_errors.deinit();
        
        var total_chars_typed: usize = 0;
        
        // Execute typing with error recovery
        for (chunks, 0..) |chunk, chunk_idx| {
            typeTextChunk(wztype_client, chunk, adaptive_delay) catch |err| {
                try typing_errors.append(TypingError{
                    .chunk_index = chunk_idx,
                    .error_type = classifyTypingError(err),
                    .recovery_attempted = true,
                });
                
                // Attempt error recovery
                attemptTypingRecovery(wztype_client, app_context) catch {
                    try typing_errors.append(TypingError{
                        .chunk_index = chunk_idx,
                        .error_type = .recovery_failed,
                        .recovery_attempted = false,
                    });
                    break;
                };
                continue;
            };
            
            total_chars_typed += chunk.len;
        }
        
        // Restore clipboard if preserved
        if (original_clipboard) |original_content| {
            restoreClipboardContent(original_content) catch {
                try typing_errors.append(TypingError{
                    .chunk_index = chunks.len,
                    .error_type = .clipboard_restore_failed,
                    .recovery_attempted = false,
                });
            };
        }
        
        const total_duration = std.time.milliTimestamp() - start_time;
        
        const result = TypingResult{
            .success = typing_errors.items.len == 0,
            .characters_typed = total_chars_typed,
            .total_duration_ms = @intCast(total_duration),
            .average_delay_ms = if (total_chars_typed > 0)
                @as(f64, @floatFromInt(total_duration)) / @as(f64, @floatFromInt(total_chars_typed))
            else
                0.0,
            .application_context = app_context,
            .errors = typing_errors.items,
        };
        
        const result_json = try json.stringify(allocator, result);
        return mcp.ToolResult.success(result_json);
    }
};

const TypingError = struct {
    chunk_index: usize,
    error_type: TypingErrorType,
    recovery_attempted: bool,
};

const TypingErrorType = enum {
    input_failed,
    timing_error,
    unicode_error,
    recovery_failed,
    clipboard_restore_failed,
};

const InputProcessingLevel = enum {
    basic,
    standard,
    advanced,
};
```

#### `hypr_send_keys`

**Purpose**: Execute sophisticated key combinations and sequences for application control and navigation
**Parameters**:
- `keys` (array): Ordered key sequence supporting modifiers, function keys, and special keys
- `delay_ms` (number, optional): Inter-key delay for complex sequences requiring timing precision

**Tool Annotations**:
- `destructiveHint`: varies (depends on key combination - some are safe, others may trigger destructive actions)
- `idempotentHint`: false (key combinations typically trigger specific application behaviors)
- `openWorldHint`: false (affects currently focused application and system-wide shortcuts)

**Returns**: Success/failure status with executed key sequence confirmation

**Implementation**:

```zig
const HyprSendKeys = struct {
    const Self = @This();
    
    pub const annotations = mcp.ToolAnnotations{
        .title = "Send Keys",
        .read_only_hint = false,
        .destructive_hint = null, // Varies by key combination
        .idempotent_hint = false,
        .open_world_hint = false,
    };
    
    pub const description = "Execute sophisticated key combinations and sequences for application control";
    
    pub const Parameters = struct {
        keys: []const []const u8,
        delay_ms: ?u32 = null,
    };
    
    pub fn execute(
        allocator: std.mem.Allocator,
        wztype_client: *wztype.Client,
        params: Parameters,
    ) !mcp.ToolResult {
        if (params.keys.len == 0) {
            return mcp.ToolResult.err("Empty key sequence provided");
        }
        
        if (params.keys.len > 10) {
            return mcp.ToolResult.err("Key sequence too long (maximum 10 keys)");
        }
        
        const delay = params.delay_ms orelse 50; // Default 50ms between keys
        
        var modifiers = wztype.Modifiers{};
        var main_key: ?wztype.Key = null;
        
        // Parse key combination
        for (params.keys) |key_str| {
            if (std.mem.eql(u8, key_str, "ctrl")) {
                modifiers.ctrl = true;
            } else if (std.mem.eql(u8, key_str, "alt")) {
                modifiers.alt = true;
            } else if (std.mem.eql(u8, key_str, "shift")) {
                modifiers.shift = true;
            } else if (std.mem.eql(u8, key_str, "super")) {
                modifiers.super = true;
            } else {
                main_key = wztype.Key.fromName(key_str) catch {
                    return mcp.ToolResult.err("Invalid key name: " ++ key_str);
                };
            }
        }
        
        if (main_key) |key| {
            try wztype_client.keyClickWithModifiers(key, modifiers);
        } else {
            return mcp.ToolResult.err("No main key specified in combination");
        }
        
        const result = try std.fmt.allocPrint(
            allocator,
            "Successfully sent key combination: {s}",
            .{try std.mem.join(allocator, "+", params.keys)},
        );
        defer allocator.free(result);
        
        return mcp.ToolResult.success(result);
    }
};
```

## Security Model

The security architecture of HyprMCP represents a comprehensive, defense-in-depth approach that recognizes the unique challenges of providing AI systems with desktop control capabilities. The model builds upon the foundational security guarantees of the Wayland protocol while adding additional layers of protection specifically designed for AI-driven automation scenarios.

### Sandboxing and Isolation

The sandboxing architecture leverages multiple isolation boundaries to contain potential security breaches and prevent unauthorized access to sensitive system resources. The implementation creates a restricted execution environment that provides AI systems with the necessary capabilities for desktop automation while preventing access to critical system functions.

**Core Isolation Mechanisms**:
- **Wayland Security Model**: Inherits Wayland's compositor-based isolation where clients cannot access other clients' content
- **Command Execution Filtering**: Strict allowlist approach for permitted application commands
- **Filesystem Access Restrictions**: Comprehensive blocking of access to sensitive system directories
- **Process Namespace Isolation**: Separate process namespaces prevent unauthorized process inspection
- **IPC Socket Restrictions**: Limited access to Hyprland IPC endpoints with capability-based access control

### Advanced Security Features

#### Command Sanitization

```zig
const std = @import("std");
const regex = @import("regex");

const CommandValidator = struct {
    allowed_commands: std.HashMap([]const u8, void),
    blocked_patterns: []const regex.Regex,
    max_command_length: usize,
    
    const Self = @This();
    
    pub fn init(allocator: std.mem.Allocator) !Self {
        var allowed_commands = std.HashMap([]const u8, void).init(allocator);
        try allowed_commands.put("firefox", {});
        try allowed_commands.put("kitty", {});
        try allowed_commands.put("code", {});
        try allowed_commands.put("nautilus", {});
        
        const blocked_patterns = [_]regex.Regex{
            try regex.compile(allocator, "rm\\s+-rf"),
            try regex.compile(allocator, "sudo\\s+"),
            try regex.compile(allocator, "\\|\\s*sh"),
        };
        
        return Self{
            .allowed_commands = allowed_commands,
            .blocked_patterns = &blocked_patterns,
            .max_command_length = 1000,
        };
    }
    
    pub fn validateAppCommand(self: *const Self, allocator: std.mem.Allocator, command: []const u8) ![]const u8 {
        // Length check
        if (command.len > self.max_command_length) {
            return error.CommandTooLong;
        }
        
        // Extract base command
        var parts = std.mem.split(u8, command, " ");
        const base_cmd = parts.next() orelse return error.EmptyCommand;
        
        // Allowlist check
        if (!self.allowed_commands.contains(base_cmd)) {
            return error.CommandNotAllowed;
        }
        
        // Pattern blocklist check
        for (self.blocked_patterns) |pattern| {
            if (pattern.isMatch(command)) {
                return error.MaliciousPattern;
            }
        }
        
        // Escape shell metacharacters
        return try shellEscape(allocator, command);
    }
};

fn shellEscape(allocator: std.mem.Allocator, input: []const u8) ![]const u8 {
    var result = std.ArrayList(u8).init(allocator);
    defer result.deinit();
    
    for (input) |char| {
        switch (char) {
            '\\', '\'', '"', ' ', '\t', '\n', '|', '&', ';', '(', ')', '<', '>', '`', '$', '*', '?', '[', ']', '{', '}' => {
                try result.append('\\');
                try result.append(char);
            },
            else => try result.append(char),
        }
    }
    
    return result.toOwnedSlice();
}
```

#### Rate Limiting Implementation

```zig
const RateLimiter = struct {
    requests: std.HashMap([]const u8, std.ArrayList(i64)),
    limits: std.HashMap([]const u8, Limit),
    allocator: std.mem.Allocator,
    
    const Self = @This();
    
    const Limit = struct {
        max_requests: u32,
        window_ms: i64,
    };
    
    pub fn init(allocator: std.mem.Allocator) Self {
        var limits = std.HashMap([]const u8, Limit).init(allocator);
        limits.put("hypr_get_windows", Limit{ .max_requests = 60, .window_ms = 60000 }) catch unreachable;
        limits.put("hypr_type_text", Limit{ .max_requests = 30, .window_ms = 60000 }) catch unreachable;
        limits.put("hypr_send_keys", Limit{ .max_requests = 100, .window_ms = 60000 }) catch unreachable;
        
        return Self{
            .requests = std.HashMap([]const u8, std.ArrayList(i64)).init(allocator),
            .limits = limits,
            .allocator = allocator,
        };
    }
    
    pub fn checkLimit(self: *Self, tool: []const u8, client_id: []const u8) !void {
        const key = try std.fmt.allocPrint(self.allocator, "{s}:{s}", .{ tool, client_id });
        defer self.allocator.free(key);
        
        const now = std.time.milliTimestamp();
        const limit = self.limits.get(tool) orelse Limit{ .max_requests = 100, .window_ms = 60000 };
        
        // Get or create request history
        var requests = self.requests.get(key) orelse blk: {
            var new_list = std.ArrayList(i64).init(self.allocator);
            try self.requests.put(try self.allocator.dupe(u8, key), new_list);
            break :blk new_list;
        };
        
        // Clean old entries
        var i: usize = 0;
        while (i < requests.items.len) {
            if (now - requests.items[i] > limit.window_ms) {
                _ = requests.orderedRemove(i);
            } else {
                i += 1;
            }
        }
        
        // Check limit
        if (requests.items.len >= limit.max_requests) {
            const retry_after_ms = limit.window_ms - (now - requests.items[0]);
            return error.RateLimited; // Could include retry_after_ms in error
        }
        
        // Add current request
        try requests.append(now);
    }
};
```

```zig
const mcp = @import("mcp-cpp");

const HyprMcpServer = struct {

    }
    
    pub fn handleToolCall(
        self: *Self,
        tool_name: []const u8,
        parameters: []const u8,
    ) !mcp.ToolResult {
        if (std.mem.eql(u8, tool_name, "hypr_get_windows")) {
            return try HyprGetWindows.execute(self.allocator, self.hyprland);
        } else if (std.mem.eql(u8, tool_name, "hypr_focus_window")) {

                HyprFocusWindow.Parameters, 
                self.allocator, 
                parameters,
            );
            defer params.deinit();
            
            return try HyprFocusWindow.execute(
                self.allocator,
                self.hyprland,
                params.value,
            );
        } else if (std.mem.eql(u8, tool_name, "hypr_type_text")) {
            const params = try std.json.parseFromSlice(
                HyprTypeText.Parameters,
                self.allocator,
                parameters,
            );
            defer params.deinit();
            
            return try HyprTypeText.execute(
                self.allocator,
                self.input,
                self.hyprland,
                params.value,
            );
        } else {
            return mcp.ToolResult.err("Unknown tool: " ++ tool_name);
        }
    }
};

pub fn main() !void {
    var gpa = std.heap.GeneralPurposeAllocator(.{}){};
    defer _ = gpa.deinit();
    const allocator = gpa.allocator();
    
    // Initialize the server
    var server = try HyprMcpServer.init(allocator);
    defer server.deinit();
    
    // Set up MCP transport (stdio)
    const stdin = std.io.getStdIn().reader();
    const stdout = std.io.getStdOut().writer();
    
    // Main server loop
    while (true) {
        const request_line = try stdin.readUntilDelimiterAlloc(allocator, '\n', 8192);
        defer allocator.free(request_line);
        
        const request = std.json.parseFromSlice(
            mcp.JsonRpcRequest,
            allocator,
            request_line,
        ) catch |err| {
            try sendError(stdout, null, "Parse error", @errorName(err));
            continue;
        };
        defer request.deinit();
        
        const result = server.handleToolCall(
            request.value.method,
            if (request.value.params) |p| 
                try std.json.stringifyAlloc(allocator, p, .{})
            else 
                "{}",
        ) catch |err| {
            try sendError(stdout, request.value.id, "Execution error", @errorName(err));
            continue;
        };
        
        try sendResponse(stdout, request.value.id, result);
    }
}

fn sendResponse(writer: anytype, id: std.json.Value, result: mcp.ToolResult) !void {
    const response = mcp.JsonRpcResponse{
        .jsonrpc = "2.0",
        .id = id,
        .result = switch (result) {
            .success => |content| .{ .content = content },
            .error => null,
        },
        .@"error" = switch (result) {
            .success => null,
            .error => |err| .{ .code = -1, .message = err },
        },
    };
    
    try std.json.stringify(response, .{}, writer);
    try writer.writeByte('\n');
}

fn sendError(writer: anytype, id: ?std.json.Value, message: []const u8, details: []const u8) !void {
    const response = mcp.JsonRpcResponse{
        .jsonrpc = "2.0",
        .id = id orelse .null,
        .result = null,
        .@"error" = .{
            .code = -32603,
            .message = message,
            .data = .{ .details = details },
        },
    };
    
    try std.json.stringify(response, .{}, writer);
    try writer.writeByte('\n');
}
```

```zig
// src/hyprland/client.zig
const std = @import("std");
const net = std.net;

const HyprlandClient = struct {
    stream: net.Stream,
    signature: []const u8,
    allocator: std.mem.Allocator,
    
    const Self = @This();
    
    pub fn connect(allocator: std.mem.Allocator) !*Self {
        const signature = std.process.getEnvVarOwned(allocator, "HYPRLAND_INSTANCE_SIGNATURE") catch {
            return error.HyprlandNotRunning;
        };
        
        const socket_path = try std.fmt.allocPrint(
            allocator,
            "/tmp/hypr/{s}/.socket2.sock",
            .{signature},
        );
        defer allocator.free(socket_path);
        
        const stream = try net.connectUnixSocket(socket_path);
        
        const self = try allocator.create(Self);
        self.* = Self{
            .stream = stream,
            .signature = signature,
            .allocator = allocator,
        };
        
        return self;
    }
    
    pub fn deinit(self: *Self) void {
        self.stream.close();
        self.allocator.free(self.signature);
        self.allocator.destroy(self);
    }
    
    pub fn dispatchCommand(self: *Self, command: []const u8) !void {
        const full_command = try std.fmt.allocPrint(
            self.allocator,
            "dispatch {s}",
            .{command},
        );
        defer self.allocator.free(full_command);
        
        try self.stream.writeAll(full_command);
        
        // Read response
        var buffer: [1024]u8 = undefined;
        const bytes_read = try self.stream.readAll(buffer[0..]);
        
        if (std.mem.startsWith(u8, buffer[0..bytes_read], "ok")) {
            return;
        } else {
            return error.CommandFailed;
        }
    }
    
    pub fn getWindows(self: *Self, allocator: std.mem.Allocator) ![]HyprWindow {
        try self.stream.writeAll("clients");
        
        var response = std.ArrayList(u8).init(allocator);
        defer response.deinit();
        
        var buffer: [4096]u8 = undefined;
        while (true) {
            const bytes_read = try self.stream.read(buffer[0..]);
            if (bytes_read == 0) break;
            try response.appendSlice(buffer[0..bytes_read]);
        }
        
        const parsed = try std.json.parseFromSlice(
            []HyprWindow,
            allocator,
            response.items,
        );
        defer parsed.deinit();
        
        return try allocator.dupe(HyprWindow, parsed.value);
    }
};
```
