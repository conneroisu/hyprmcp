# Getting Started

This guide will help you get up and running with HyprMCP quickly.

## Prerequisites

Before you begin, ensure you have:

- Hyprland window manager installed and running
- Rust toolchain (if building from source)
- Basic familiarity with MCP (Model Context Protocol)

## Quick Start

1. **Installation**: Follow the [Installation](./installation.md) guide to install HyprMCP
2. **Configuration**: Set up your configuration as described in [Configuration](./configuration.md)
3. **Usage**: Learn how to use HyprMCP in the [Usage](./usage.md) section

## Basic Example

Once installed and configured, you can start using HyprMCP to interact with your Hyprland desktop:

```bash
# Example command to start the MCP server
hyprmcp serve
```

The server will start and be ready to accept MCP requests for Hyprland operations.
