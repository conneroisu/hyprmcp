# Introduction

Welcome to the HyprMCP documentation! This book provides comprehensive documentation for the HyprMCP project.

## What is HyprMCP?

HyprMCP is a Model Context Protocol (MCP) server that provides integration with Hyprland window manager functionality. It allows AI assistants and other tools to interact with your Hyprland desktop environment through a standardized protocol.

## Features

- Window management operations
- Workspace control
- Desktop information queries
- Configuration management
- Event monitoring
